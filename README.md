# Image Slider 🖼️

A simple and responsive image slider built using **HTML, CSS, and JavaScript**.

## Features
- Automatically slides through multiple images
- Next and Previous buttons for manual control
- Smooth transition animations
- Fully responsive design for desktop and mobile

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open `index.html` in your browser.
2. Use the **Next** and **Previous** buttons to navigate through images.
3. Watch the slider automatically transition through images.
